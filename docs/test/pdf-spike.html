Technical Details

This test validates the following approach:

  1. Render circles to Canvas using circle algorithm
  2. Convert Canvas to PNG via canvas.toDataURL('image/png')
  3. Embed PNG in PDF using jsPDF's addImage() method
  4. Download PDF with metadata

Why PNG Embedding (Not Vector)?

  • File Size: Vector circles (250k circles) = 10-50MB; PNG = <5MB
  • Compatibility: Works consistently across all PDF viewers
  • Performance: Fast PDF generation without complex calculations
  • Quality: Rasterized circles sufficient for visual needs

Circle Algorithm Formula

normalized_darkness = (255 - pixel_grayscale_value) / 255
circle_radius = min_radius + (normalized_darkness * (max_radius - min_radius))

// Example:
// Black pixel (0): normalized = 1.0 → radius = 1 + (1.0 * 14) = 15px
// White pixel (255): normalized = 0.0 → radius = 1 + (0.0 * 14) = 1px
// Gray pixel (127): normalized = 0.5 → radius = 1 + (0.5 * 14) = 8px
